# 천타

중학생을 위한 한글 자리·단어·짧은 글 연습 웹앱입니다. Python 3.12 이상과 기본 라이브러리만 사용하며 별도 설치가 필요 없습니다.

## 실행

```sh
cd /workspace/cheonta
read -rs -p '관리자 비밀번호: ' CHEONTA_ADMIN_PASSWORD
export CHEONTA_ADMIN_PASSWORD
python3 server.py
```

기본 포트는 8000입니다. `PORT`, `HOST` 환경변수로 변경할 수 있습니다. 교사가 관리자 화면의 ‘학생 명단 등록’에서 반과 이름을 먼저 추가합니다. 학생은 첫 화면의 ‘처음 왔어요’에서 반 또는 이름으로 명단을 검색하고 본인을 선택한 뒤 숫자 4자리 비밀번호만 설정합니다. 명단에 없는 학생은 직접 계정을 만들 수 없으며, 이미 비밀번호를 설정한 학생은 검색 결과에서 제외됩니다. 기존 계정과 학습 기록은 그대로 유지됩니다. 다음 방문에는 로그인 탭을 사용합니다. 같은 반의 동명이인은 이름에 번호를 붙여 구분하세요. 브라우저에는 반·이름만 기억하고 비밀번호는 저장하지 않습니다. 비밀번호 관리자의 저장 기능은 사용할 수 있습니다.

교사는 로그인 화면 아래 관리자 로그인을 사용합니다. 관리자 비밀번호를 지정하지 않으면 관리자 로그인이 비활성화됩니다. 학생 명단 추가, 가입 상태 확인, 학생 계정 수정, 4자리 비밀번호 재설정, 계정과 관련 기록 삭제가 가능합니다. 수정·삭제하면 해당 학생의 기존 로그인도 해제됩니다.

## 기록과 순위

- 서버의 `data/cheonta.sqlite3`에 계정과 기록을 영구 저장합니다. `CHEONTA_DB`로 경로를 지정할 수 있습니다. 실행 중 데이터베이스 백업은 SQLite backup API 등을 사용하세요.
- 정확도는 위치별 일치 글자 수 / (입력 길이와 제시문 길이 중 큰 값)입니다. 공백·문장부호도 비교합니다. 수정 후 최종 입력이 제시문과 완전히 같으면 100%입니다.
- 타수는 한글 두벌식 자모 입력 수를 분당 환산합니다. 된소리와 겹받침·복합모음은 2타로 계산하고 공백·문장부호는 1타로 계산합니다. Shift 자체는 별도 타수로 세지 않습니다.
- 첫 입력부터 제출까지 시간을 측정합니다. 서버에서 시간을 계산하며, 네트워크 지연에 따라 소폭 차이가 있을 수 있습니다.
- 모든 제출의 타수와 정확도를 저장합니다. 100% 미만은 평균·순위에 반영하지 않고 동일 문장을 다시 제시합니다.
- 개인 순위는 정확도 100%인 자리·단어·짧은 글 연습 타수의 산술평균입니다. 반별 순위는 기록이 있는 학생들의 개인 평균을 다시 평균합니다. 기록이 없는 학생은 반 평균에서 제외합니다.
- 동점은 공동 순위입니다. 화면은 정수로 반올림해 표시하지만 실제 순위는 원래 값으로 계산합니다.

## 검증

```sh
python3 -m unittest discover -s tests -v
```

실제 HTTP 서버와 임시 SQLite DB로 가입, 재로그인, 오답 재연습, 기록, 순위, 대회 요청 차단과 과거 대회 기록의 랭킹 제외, 관리자 권한과 계정 관리를 검사합니다.

이 환경의 Playwright와 `/usr/bin/chromium`을 사용하는 화면 검사도 실행할 수 있습니다. 임시 데이터베이스와 8765 포트를 사용하며 실행 후 테스트 서버를 종료합니다.

```sh
python3 tests/browser_smoke.py
```

## 운영

학교 내부의 신뢰할 수 있는 환경을 위한 기본 구현입니다. 외부 공개 시 HTTPS 역방향 프록시와 접근 제어, 데이터 백업, 학생 개인정보 보관 정책을 적용하세요. 세션은 메모리에 있어 서버 재시작 시 다시 로그인해야 합니다. 비밀번호는 개별 salt를 사용한 PBKDF2 해시로 저장합니다. 학생별·IP별 로그인은 5분에 10회로 제한합니다. 클라이언트 자동 입력을 완전히 방지하는 공인 대회 감독·부정행위 탐지 시스템은 포함하지 않습니다.

## 연습 단계

왼쪽 메뉴는 자리연습, 단어연습, 짧은 글 연습, 나의 기록, 실시간 랭킹 순서입니다. 로그인하면 자리연습부터 시작합니다. 각 연습 메뉴를 선택하면 해당 단계로 바로 이동합니다. 자리연습의 글자 사이 공백도 입력해야 합니다. 각 단계의 진행 위치는 로그인한 세션 동안 유지되며, 정확도 100% 미만이면 같은 문제를 재연습합니다.

실시간 랭킹은 정확도 100%인 자리·단어·짧은 글 연습의 평균타수로 계산합니다. 개인 순위와 반별 순위를 제공하며, 랭킹 화면은 10초마다 갱신됩니다. 타자대회 기능은 제거했습니다. 기존 대회 기록은 보존하되 랭킹 및 관리자 평균타수에서 제외합니다. 기존 DB 변경 없이 업데이트할 수 있습니다.

## CSV·엑셀로 명단 등록

관리자 로그인 → 학생 관리 → **엑셀 양식 다운로드**를 누릅니다. 첫 행의 `반`, `이름`은 유지하고 2행부터 학생을 입력한 뒤 `.xlsx`로 저장합니다. **학생 명단 파일**에서 파일을 선택하고 **파일 업로드 및 명단 생성**을 누르면 비밀번호 설정 대기 상태로 등록됩니다. 첫 번째 시트의 A·B열만 읽으며 수식 대신 값을 입력하세요. `.xls`는 엑셀에서 `.xlsx`로 다시 저장하세요.

CSV는 첫 행을 `반,이름`으로 작성합니다. UTF-8(BOM 포함 가능)과 Windows 한글(CP949)을 지원합니다. 파일 크기는 최대 1MB, 한 번에 2,000명까지 등록할 수 있습니다. 빈 행은 무시하고 같은 반·이름은 건너뜁니다. 기존 비밀번호와 학습 기록은 유지됩니다. 잘못된 행이 있으면 오류 위치를 안내하고 전체 등록을 취소합니다.

Windows CMD 실행 예시(프로그램 폴더에서 실행):

```cmd
set "CHEONTA_ADMIN_PASSWORD=원하는비밀번호"
python server.py
```

## 누적 연습 시간

실시간 랭킹의 개인 순위와 반별 순위에 누적 연습 시간을 표시합니다. 반별 시간은 반 학생들의 **전체 누적 시간의 합**이며 평균이 아닙니다. 자리·단어·짧은 글 연습 모두 포함하며, 오답이나 아직 제출하지 않은 연습도 집계합니다. 정확한 기록이 없는 학생도 연습 시간이 있으면 표시하며 평균타수와 순위는 `—`로 표시합니다. 기존 평균타수 순위 계산은 유지합니다.

실제 입력 이벤트 사이 간격이 2초 이하일 때만 해당 간격을 합산합니다. 첫 입력 전 대기, 마지막 입력 이후, 2초를 넘긴 입력 간격 전체, 입력창에서 포커스가 벗어나거나 창이 숨겨진 시간은 제외합니다. 한글 조합과 삭제 입력도 포함합니다. 이 방식은 입력 이벤트로 추정한 활동 시간이며 키를 누르는 물리적 시간을 정밀 측정하는 방식은 아닙니다.

연습 시간은 5초마다, 제출·메뉴 이동·로그아웃 시 저장합니다. 페이지 종료 시에도 저장을 시도하지만 강제 종료나 네트워크 단절 시 마지막 저장 이후 시간이 유실될 수 있습니다. 같은 누적값의 재전송은 중복 합산하지 않습니다. DB에 자동으로 시간 저장 테이블을 추가하며 기존 계정·기록을 유지합니다. 과거 기록에는 입력 시간 정보가 없으므로 업데이트 후부터 시간을 집계합니다.

## 다양한 연습 문제

단어 연습은 국어, 수학, 과학, 사회, 역사, 도덕, 기술·가정, 예술·체육 등 중학교 주요 교과에서 접하는 어휘 310개를 제공합니다. 교과 어휘를 선별한 연습용 목록이며 특정 교과서의 공식 전체 단어 목록은 아닙니다. 문제 위에 교과 분류가 표시됩니다.

짧은 글 연습은 속담 46개, 출처가 표시된 명언 12개, 한국 고전 문학 구절 21개, 창작 연습 문장 16개 등 총 95개를 제공합니다. 문학 구절은 윤동주·김소월·이육사 등의 시와 이상 《날개》, 김유정 《동백꽃》, 이효석 《메밀꽃 필 무렵》 등 저작권 보호기간이 지난 한국어 원문에서 발췌했습니다. 한 줄 입력을 위해 행갈이와 일부 띄어쓰기·문장부호를 정리했습니다. 명언의 외국어 원전은 연습용으로 직접 옮긴 표현입니다. 작품·작가 또는 명언의 출처를 문제 위에 표시합니다.

단어와 짧은 글은 각각 목록을 무작위로 섞어 한 바퀴 동안 중복 없이 제시하며, 다음 바퀴의 첫 문제도 직전 문제와 겹치지 않습니다. 오답이면 같은 문제를 재연습하고, 메뉴를 이동했다 돌아와도 현재 문제를 유지합니다. 자리연습은 기본 자리부터 기존 순서를 유지합니다. 문제 순서는 로그인 세션 동안 유지되며 재로그인하면 새로 섞습니다. 계정·기록·누적 연습 시간의 저장 방식은 유지됩니다.

## PC 화면 디자인

1920×1080 PC 화면을 기준으로 보라·핑크·블루 그라데이션, 컬러 통계 카드, 키보드 안내를 적용했습니다. 왼쪽 메뉴의 위치·순서·내용은 유지합니다. 모바일용 메뉴 전환은 사용하지 않습니다. 창 크기를 기준으로 1920×1080 디자인이 화면 안에 들어오도록 전체 UI를 같은 비율로 자동 축소합니다. 창 크기를 바꾸거나 브라우저 배율을 변경하면 다시 계산합니다. 1920×1080, 1920×940, 1600×900, 1536×864, 1366×768, 1280×720, 1024×768에서 화면과 관리자 편집창을 검사했습니다.

페이지 스크롤 없이 사용할 수 있도록 연습 화면을 화면 높이에 맞추고, 기록·랭킹은 8행, 관리자 학생 명단은 4행씩 이전·다음 버튼으로 표시합니다. 가입 명단 검색은 3명씩 표시합니다. 데이터는 삭제하거나 줄이지 않으며 다음 페이지에서 계속 볼 수 있습니다.

PC 화면 검증(Playwright와 Chromium이 설치된 환경):

```sh
python3 tests/desktop_layout.py
```

## 개인 랭킹 공개 범위

실시간 개인 랭킹은 평균타수 내림차순으로 상위 100명까지만 제공합니다. 경계에서 동점이면 기존의 학생 ID 순서로 공개 대상을 정하므로 최대 100명을 유지합니다. 101번째 이후 학생은 랭킹 API 응답에도 포함하지 않아 다음 페이지로 조회할 수 없습니다. 반별 평균타수·참여 인원·누적 시간 합계는 전체 학생을 기준으로 계산합니다. 관리자 학생 명단과 개인의 연습 기록은 그대로 유지합니다.
