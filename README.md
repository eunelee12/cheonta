# 천타

중학생을 위한 한글 짧은 글 연습 · 타자대회 웹앱입니다. Python 3.12 이상과 기본 라이브러리만 사용하며 별도 설치가 필요 없습니다.

## 실행

```sh
cd /workspace/cheonta
read -rs -p '관리자 비밀번호: ' CHEONTA_ADMIN_PASSWORD
export CHEONTA_ADMIN_PASSWORD
python3 server.py
```

기본 포트는 8000입니다. `PORT`, `HOST` 환경변수로 변경할 수 있습니다. 첫 화면에서 학생이 ‘처음 왔어요’를 선택해 반·이름·숫자 4자리 비밀번호로 가입합니다. 다음 방문에는 로그인 탭을 사용합니다. 같은 반의 동명이인은 이름에 번호를 붙여 구분하세요. 브라우저에는 반·이름만 기억하고 비밀번호는 저장하지 않습니다. 비밀번호 관리자의 저장 기능은 사용할 수 있습니다.

교사는 로그인 화면 아래 관리자 로그인을 사용합니다. 관리자 비밀번호를 지정하지 않으면 관리자 로그인이 비활성화됩니다. 학생 계정 수정, 4자리 비밀번호 재설정, 계정과 관련 기록 삭제가 가능합니다. 수정·삭제하면 해당 학생의 기존 로그인도 해제됩니다.

## 기록과 순위

- 서버의 `data/cheonta.sqlite3`에 계정과 기록을 영구 저장합니다. `CHEONTA_DB`로 경로를 지정할 수 있습니다. 실행 중 데이터베이스 백업은 SQLite backup API 등을 사용하세요.
- 정확도는 위치별 일치 글자 수 / (입력 길이와 제시문 길이 중 큰 값)입니다. 공백·문장부호도 비교합니다. 수정 후 최종 입력이 제시문과 완전히 같으면 100%입니다.
- 타수는 한글 두벌식 자모 입력 수를 분당 환산합니다. 된소리와 겹받침·복합모음은 2타로 계산하고 공백·문장부호는 1타로 계산합니다. Shift 자체는 별도 타수로 세지 않습니다.
- 첫 입력부터 제출까지 시간을 측정합니다. 서버에서 시간을 계산하며, 네트워크 지연에 따라 소폭 차이가 있을 수 있습니다.
- 모든 제출의 타수와 정확도를 저장합니다. 100% 미만은 평균·순위에 반영하지 않고 동일 문장을 다시 제시합니다.
- 개인 순위는 정확도 100%인 전체 연습·대회 문장 타수의 산술평균입니다. 반별 순위는 기록이 있는 학생들의 개인 평균을 다시 평균합니다. 기록이 없는 학생은 반 평균에서 제외합니다.
- 대회는 모든 참가자가 같은 5문장을 순서대로 입력합니다. 5문장 모두 정확하게 완주해야 대회 기록이 저장되며, 5문장 타수의 평균 중 개인 최고 기록으로 순위를 매깁니다. 실패한 문장은 재입력합니다. 페이지를 떠나면 진행 중인 대회는 중단되고 완주 기록은 남지 않지만 이미 제출한 문장 기록은 유지됩니다.
- 동점은 공동 순위입니다. 화면은 정수로 반올림해 표시하지만 실제 순위는 원래 값으로 계산합니다.

## 검증

```sh
python3 -m unittest discover -s tests -v
```

실제 HTTP 서버와 임시 SQLite DB로 가입, 재로그인, 오답 재연습, 기록, 순위, 대회 완주, 관리자 권한과 계정 관리를 검사합니다.

이 환경의 Playwright와 `/usr/bin/chromium`을 사용하는 화면 검사도 실행할 수 있습니다. 임시 데이터베이스와 8765 포트를 사용하며 실행 후 테스트 서버를 종료합니다.

```sh
python3 tests/browser_smoke.py
```

## 운영

학교 내부의 신뢰할 수 있는 환경을 위한 기본 구현입니다. 외부 공개 시 HTTPS 역방향 프록시와 접근 제어, 데이터 백업, 학생 개인정보 보관 정책을 적용하세요. 세션과 대회 진행은 메모리에 있어 서버 재시작 시 다시 로그인해야 합니다. 비밀번호는 개별 salt를 사용한 PBKDF2 해시로 저장합니다. 학생별·IP별 로그인은 5분에 10회로 제한합니다. 클라이언트 자동 입력을 완전히 방지하는 공인 대회 감독·부정행위 탐지 시스템은 포함하지 않습니다.

## 연습 단계

연습하기 상단에서 자리연습(기본 자리·윗자리·아랫자리의 자음과 모음), 단어연습(쉬운 단어·받침·복합 모음·겹받침), 짧은 글 연습(명언·속담·긍정 문장)을 선택합니다. 자리연습의 글자 사이 공백도 입력해야 합니다. 각 단계의 진행 위치는 로그인한 세션 동안 유지되며, 정확도 100% 미만이면 같은 문제를 재연습합니다. 기록에는 연습 단계가 함께 저장되며, 각 단계의 정확한 기록은 기존 평균타수·순위에 함께 반영됩니다. 타자대회는 기존의 동일한 짧은 글 5문장 규칙을 유지합니다. 기존 DB 변경 없이 업데이트할 수 있습니다.
